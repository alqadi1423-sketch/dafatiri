# دفاتري

دفاتر حسابات العائلة على الجوال: تسجيل الديون والسداد والسحب والإبراء، وكشف حساب لكل اسم.

## البيانات
لا يحتوي الكود أي اسم أو دفتر أو رقم. كل البيانات في قاعدة البيانات فقط، وتُنشأ من داخل الموقع:
الدفاتر من «دفتر جديد»، والأشخاص من «الأشخاص» أو من صفحة الدفتر، والحركات من صفحة حساب الشخص.
كل شخص له سجل واحد يجمع حساباته في كل الدفاتر، ويُربط بحساب دخول عبر رابط دعوة لمرة واحدة.
أنواع الدفاتر قوالب عامة في `functions/_lib/kinds.js`.

## الصلاحيات
- الدخول باسم مستخدم وكلمة مرور خاصة بالموقع، بلا أي خدمة خارجية. كلمات المرور مجزّأة (PBKDF2) والجلسة في ملف تعريف ارتباط محمي لمدة 30 يومًا.
- 10 محاولات خاطئة خلال 15 دقيقة توقف الدخول مؤقتًا لذلك الاسم أو العنوان.
- **المالك**: يُنشأ عند أول نشر من `OWNER_USERNAME` و`OWNER_PASSWORD`، ثم يغيّر كلمة مروره من الموقع. يسجّل ويحذف ويفتح حسابات، ويضيف أفراد العائلة ويعيّن كلمات مرورهم ويوقفهم.
- **فرد العائلة**: يرى فقط الكشوف التي ربطها المالك به في دفتر 2 و3، قراءة فقط، ويغيّر كلمة مروره بنفسه.
- الحذف منطقي: الحركة المحذوفة تبقى في قاعدة البيانات مع وقت الحذف ومن حذفها.
- المبالغ تُحفظ بالهللة (أعداد صحيحة).

## البنية
- `public/`: الواجهة (HTML وCSS وJS بلا أدوات بناء).
- `functions/api/`: واجهة البيانات على Cloudflare Pages Functions.
- قاعدة البيانات: Cloudflare D1، مع استرجاع لأي لحظة خلال 7 أيام.

## النشر
سير `deploy` يعمل عند كل رفع إلى `main`: يجهّز قاعدة البيانات ومشروع الموقع أول مرة،
ثم الترحيلات وحساب المالك (أول مرة فقط) ثم النشر. أسراره: `CLOUDFLARE_API_TOKEN`، `CLOUDFLARE_ACCOUNT_ID`، `OWNER_USERNAME`، `OWNER_PASSWORD`.

صلاحيات مفتاح Cloudflare (على مستوى الحساب):
- D1: Edit
- Cloudflare Pages: Edit

سير `backup` (يدوي) يصدّر قاعدة البيانات إلى فرع `backups`. وCloudflare تتيح الاسترجاع لأي لحظة خلال آخر 7 أيام.

## التطوير المحلي
`npm install` ثم `npm run dev` (مالك تجريبي: `owner` / `owner-pass-1`)، والاختبارات `npm test`.
