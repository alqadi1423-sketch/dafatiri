# دفاتري

دفاتر حسابات العائلة على الجوال: تسجيل الديون والسداد والسحب والإبراء، وكشف حساب لكل اسم.

## الدفاتر
1. **دفتر 1: خاص**: للمالك وحده، لا يُربط بأحد.
2. **دفتر 2: صندوق العائلة**: الحصص والإيداع والسحب.
3. **دفتر 3: ديون العائلة على علي حصن**: أصل الدين والسداد والإبراء.

البيانات الافتتاحية (20 نوفمبر 2026) في `migrations/0002_seed.sql`، مولّدة من `scripts/build-seed.py`.

## الصلاحيات
- الدخول عبر Cloudflare Access برمز يصل للبريد، والموقع يتحقق من توقيع الدخول بنفسه.
- **المالك** (`OWNER_EMAIL`): يسجّل ويحذف ويفتح حسابات ويربطها بالبريد.
- **فرد العائلة**: يرى فقط الحسابات المربوطة ببريده في دفتر 2 و3، قراءة فقط.
- من يدخل ببريد غير مربوط لا يرى شيئًا.
- الحذف منطقي: الحركة المحذوفة تبقى في قاعدة البيانات مع وقت الحذف ومن حذفها.
- المبالغ تُحفظ بالهللة (أعداد صحيحة).

## البنية
- `public/`: الواجهة (HTML وCSS وJS بلا أدوات بناء).
- `functions/api/`: واجهة البيانات على Cloudflare Pages Functions.
- قاعدة البيانات: Cloudflare D1، مع استرجاع لأي لحظة خلال 7 أيام.

## النشر
سير `deploy` يعمل عند كل رفع إلى `main`: يجهّز قاعدة البيانات ومشروع الموقع وحماية الدخول أول مرة،
ثم الترحيلات ثم النشر. أسراره: `CLOUDFLARE_API_TOKEN`، `CLOUDFLARE_ACCOUNT_ID`، `OWNER_EMAIL`.

صلاحيات مفتاح Cloudflare (على مستوى الحساب):
- D1: Edit
- Cloudflare Pages: Edit
- Access: Apps and Policies: Edit
- Access: Organizations, Identity Providers, and Groups: Edit

قبل أول نشر: تفعيل Zero Trust مرة واحدة من لوحة Cloudflare (اختيار اسم الفريق والخطة المجانية).

سير `backup` يصدّر قاعدة البيانات يوميًا إلى فرع `backups` ويبقي آخر 90 نسخة.

## التطوير المحلي
`npm install` ثم `npm run dev` (يعمل بمالك تجريبي `owner@example.com`)، والاختبارات `npm test`.
